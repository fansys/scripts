# 公共脚本

此目录保存各平台共用的插件脚本。

## 维护约定

- 每个插件使用一个独立目录。
- 插件脚本、配置、资源及其他相关文件全部放在对应插件目录中。
- 每个插件目录必须包含 `README.md`，说明插件用途、文件作用、配置方式及使用方法。
- 平台订阅文件直接引用此目录中的插件 JavaScript 文件。
